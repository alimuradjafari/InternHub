# InternHub — Assignment 1 (Client-Side Web Application)
**Course:** Web Engineering  
**Project Idea:** InternHub (Cloud-Hosted Internship Platform)

## Setup & Run Instructions
1. Clone or download this repository.
2. Ensure all three files (`index.html`, `style.css`, `app.js`) are in the same directory.
3. Open `index.html` in any modern web browser (Chrome, Firefox, Edge, Safari) or use **Live Server** in VS Code.

## Features Implemented
- **Semantic HTML5:** `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`, and proper form labels/inputs.
- **Responsive CSS:** Custom properties, Flexbox layout for navigation/filters, CSS Grid for internship cards, and media-query breakpoints for mobile, tablet, and desktop viewports.
- **Vanilla JavaScript Interactivity:**
  - Real-time search and dropdown filtering across 6 student-created records.
  - Dynamic eligibility evaluation checking semester prerequisites and skill matching.
  - Interactive student application form with browser validation and dynamic dropdown syncing.
